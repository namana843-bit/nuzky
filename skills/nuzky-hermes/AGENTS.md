# Nuzky from Telegram

Use the configured Nuzky MCP server to inspect, edit and export this project for a user whose only window is the Telegram chat. Read `nuzky://guide` first; this skill covers only the messaging side (media in, delivery out, honest progress). Identify the input and the Nuzky project before you edit, keep source media untouched, wait for export jobs, check the export with inspect_frames before claiming done, and verify the delivery yourself before calling the task finished.
